# Architecture

`apps/web` is the React/Vite interface, `apps/server` is a loopback Fastify API and local compiler, `scripts/poster.ts` is the CLI, and `templates` contains the three LaTeX layouts plus shared macros. The API stores project metadata in `.overposter/projects/<id>/project.json`, editable source in `source/`, generated PDFs in `.overposter/builds/`, and bare Git version repositories in `.overposter/versions/`.

The editor sends file writes with an ETag. A stale ETag produces a conflict, retaining the browser draft for recovery. Compile first saves the active editor buffer, then stages source into a temporary directory and runs local XeLaTeX and `xdvipdfmx` without shell escape. A successful build replaces the PDF and creates a checkpoint; failure preserves the previous PDF. Preflight checks page count, dimensions, fonts, and image DPI.

Local mode is for a single trusted user on loopback. ZIP imports are untrusted until explicitly approved after source inspection. XeLaTeX is not an isolation boundary. Hosted mode fails at startup and must remain disabled until an authenticated API, project authorization, persistent collaboration, and separate isolated compiler worker have passed integration tests.

The loopback test harness (`NODE_ENV=test`, `OVERPOSTER_MODE=test-hosted`, `OVERPOSTER_TEST_IDENTITIES=1`) adds per-project roles in `.overposter/access.sqlite` and Yjs state in `.overposter/collaboration/`. It identifies simulated users by an explicit test header or a test-only browser cookie. REST routes enforce owner/editor/viewer rights; a WebSocket route merges and persists updates for editable text files. Checkpoint and restore flush the shared state. The browser editor uses this protocol in test mode, with presence and persistence acknowledgments. Test identities are not suitable for a public origin. TeX compilation remains disabled in this mode.

Manual Overroot project references live in `.overposter/projects/<id>/overroot-link.json`, outside poster source and Git checkpoints. They carry a user-supplied stable ID, HTTPS deep link, author, and timestamp. The link is validated against the configured Overroot origin and has optimistic version checks; it makes no remote API call, does not verify Overroot access, and does not sync source or membership.

Identity resolution is isolated behind `apps/server/src/identity.ts`. Local mode returns a single local principal. The guarded test mode accepts a simulated subject, while public hosted mode fails startup because the site account contract and isolated compiler are absent. Test-mode membership is stored in a versioned SQLite schema. The prior JSON grants are imported once without deleting them; see [membership migration](ACCESS_MIGRATION.md).
