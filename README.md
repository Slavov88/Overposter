# Overposter

Overposter is a local studio for designing and compiling large-format research posters. It combines modular LaTeX projects, three poster layouts, a source editor, PDF preview, and print preflight in one repository.

## Requirements

- Node.js 24, pnpm 11, Python 3.11 or newer
- A local XeLaTeX installation with `xelatex` and `xdvipdfmx` on `PATH` (MiKTeX on Windows or TeX Live on Linux/macOS)
- Python package `pymupdf==1.28.2`

```bash
python -m pip install -r requirements.txt
pnpm install
pnpm poster:dev
```

Open `http://127.0.0.1:5173`. The service binds to the local loopback address. The browser stores projects in `.overposter/projects/` and outputs in `.overposter/builds/`.

The compiler runs local XeLaTeX followed by `xdvipdfmx` in a temporary directory, with shell escape disabled. Imported ZIP projects require explicit approval in the local interface after you review their source. Hosted compilation is disabled until a separate isolated TeX worker is provisioned and verified.

## Make a poster

1. Select **New poster**, a layout, and A0, A1, or custom dimensions.
2. Edit `sections/*.tex` in the file tree. `poster.tex` controls the layout; `config.tex` is generated by poster settings.
3. Select **Compile poster**. The editor saves before compilation. The existing preview stays available if a new build fails.
4. Review the PDF and the preflight report. Download the vector PDF or export the source ZIP.

The layouts are **Academic Classic**, **Modern ML**, and **Visual Results**. Each contains a complete starting structure with sections for motivation, method, study, results, conclusions, and references. The sample in `examples/sample-ml-poster/` has an illustrative diagram, equation, table, and chart. Its numbers are synthetic and are labelled as such.

## CLI

```bash
pnpm poster:new -- --name "My poster" --theme modern-ml
pnpm poster:build                         # build the sample
pnpm poster:build -- --source path/to/project --out path/to/poster.pdf
pnpm poster:build -- --id PROJECT_ID      # build a workspace project
pnpm poster:check -- --pdf path/to/poster.pdf --config path/to/poster.json
pnpm poster:check -- --pdf path/to/poster.pdf --config path/to/poster.json --json --out report.json
pnpm poster:export -- --id PROJECT_ID --out poster-source.zip
pnpm examples:build                       # all three layouts and sample
pnpm poster:clean                         # generated PDFs only
```

The build command fails if TeX fails, the PDF has more than one page, or its measured size differs from the requested size by more than 0.5 mm. It writes `<poster.pdf>.preflight.json` beside a successful PDF. `poster:check` prints a readable summary; `--json` prints the full machine-readable report and `--out` saves it. Preflight checks font embedding and effective DPI of raster images and gives warnings for uncertain print issues. It cannot prove that all content is aesthetically aligned or detect every clipped vector graphic.

Local compilation is intended for poster source you trust. Install MiKTeX or TeX Live and make `xelatex` and `xdvipdfmx` available on `PATH`. A failed build preserves the previous PDF.

## Source format

Each project has `poster.json`, `poster.tex`, generated `config.tex`, `sections/`, `figures/`, `assets/`, and `references.bib`. Include figures with relative paths such as `\includegraphics{figures/plot.pdf}`. Put an optional institutional logo at `assets/logo.pdf`; all layouts include it automatically. Convert SVG to vector PDF with Inkscape (`inkscape plot.svg --export-filename=plot.pdf`) before including it; shell escape is disabled during compilation.

Custom width and height are accepted from 200 to 3000 mm. TeX/PDF engines may reject extreme page sizes; compilation reports the engine error. A1 landscape is the default.

## Development and CI

```bash
pnpm typecheck
pnpm lint
pnpm test
pnpm build
pnpm examples:build
```

GitHub Actions installs TeX Live on Ubuntu, runs static checks and tests, builds all examples with XeLaTeX, checks their physical sizes and page count, then uploads PDFs and preflight JSON as workflow artifacts. Open a successful workflow run and download **overposter-example-pdfs** and **overposter-preflight-reports** under **Artifacts**.

Overposter is a standalone, single-user local application. Multiuser collaboration and hosted accounts are outside this release. The project and compiler interfaces are file based so they can be integrated with a collaborative service later.
